The linked companion is the complete accessible explanation of every page and
its boundaries. The selected release's commands and record contracts define
executable behavior. The artwork does not start workers, execute schedules,
grant permissions, synchronize remote writers, or certify production readiness.
Agent 0/user retains acceptance, Agent X records observations, Agent Y carries
an explicitly selected CLI handoff, Agent Z supplies a fixed advisory review,
and Agent Alpha selects bounded references on demand.

`WORK/TASKS.json` remains the sole task-state authority. ROOT links canonical
task IDs to actual harness and optional bot observations, retaining revision,
time, and evidence. Its delta is read-only. Agent 0 reconciles affected items
with authorized real tools and records a fresh readback. One harness phase may
cover several canonical tasks; several bot attempts may concern the same task.
Equal list counts do not establish alignment, and external `completed` does not
mark canonical work `done`. Stop after a checkpoint or concrete blocker rather
than repeating unchanged observations and reviews.

Use the [generation/correction prompts](../../.SYSTEMX/MEDIA/Reference/systemx-field-guide-prompts.md)
and [per-page asset metadata](../../.SYSTEMX/MEDIA/Reference/ASSETS.json) for
production provenance. The current [Visual Guide](https://github.com/WayneTechLab/dotSYSTEMX/wiki/Visual-Guide)
provides the public manual entry point.
