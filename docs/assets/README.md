# .SYSTEMX documentation graphics

The standalone product mark is [systemx-logo.png](systemx-logo.png).
The product remains styled `.SYSTEMX`; Wayne Tech Lab LLC attribution appears
in project information. The [logo prompt and provenance](IMAGE-PROMPTS.md)
remain available here.

The current public visuals live in the portable
[media library](../../.SYSTEMX/MEDIA/README.md). It keeps the four foundational
4K JPEG field-guide pages and adds four current feature guides and one
standalone SVG for each of the seven agent roles. The
[current text companion](../../.SYSTEMX/MEDIA/Reference/current-visual-guide.md)
provides the full explanation and role boundaries. The
[asset record](../../.SYSTEMX/MEDIA/Reference/ASSETS.json) lists exact bytes,
hashes, native art dimensions, and export dimensions.

The prior video posters, coordination diagrams, project-wave graphics,
shared-workspace renders, and legacy workflow artwork were archived from the
current branch after exact-byte verification. They remain available in
[immutable alpha.7 history](https://github.com/WayneTechLab/dotSYSTEMX/tree/v1.11.0-alpha.7/docs/assets).
Hosted videos remain linked from the [public manual](https://github.com/WayneTechLab/dotSYSTEMX/wiki);
this beta adds no new video. Raw scenes, narration, renders, and authoring
payloads remain outside the reusable source distribution.

The diagrams explain responsibilities. They do not start workers, synchronize
providers, grant credentials, or certify security. Follow the selected
installation's [CLI guide](../../.SYSTEMX/docs/CLI-TOOLS.md) for executable
commands.
