# Help and support

.SYSTEMX is alpha: use at your own risk, expect possible daily changes, and pin a
reviewed release. Start with [first-time setup](https://github.com/WayneTechLab/dotSYSTEMX/wiki/First-Time-Setup),
[release policy](https://github.com/WayneTechLab/dotSYSTEMX/wiki/Release-Policy),
and [uninstall and cleanup](https://github.com/WayneTechLab/dotSYSTEMX/wiki/Uninstall-and-Cleanup).

For bugs, questions, and feature requests, use
[GitHub Issues](https://github.com/WayneTechLab/dotSYSTEMX/issues).
Include `systemx --version`, the selected defaults version from
`systemx status --target PATH`, OS/Python version, setup profile, expected behavior,
and a minimal reproduction in a temporary project. An old copied root `VERSION`
may differ from the active defaults; report both when relevant.

Review and redact logs before posting. Status and operation receipts can contain
local paths; exported context can contain private project data. Share only the
smallest sanitized evidence needed. Sensitive vulnerabilities use the
[private reporting path](SECURITY.md).

Support is community/maintainer best effort, without an SLA or guaranteed release
date. This project does not operate a hosted service, manage your cloud accounts,
or install an MCP server. A passing template check is not a production audit.
