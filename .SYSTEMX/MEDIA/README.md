# .SYSTEMX reference library

This folder holds static reference documents and images: the latest published
white paper, the four-part system field guide, accessible text companions, and
workflow cards. Read only the material relevant to the current task. Application
facts, task history, memory, and owner payloads belong in the selected project's
records and DATA rather than in this reusable reference library.

## White paper

**Portable Project Coordination for AI-Assisted Work — edition 2.0.** The paper
explains canonical task authority, plans, Agent 0/X/Y/Z/Alpha, ROOT observations,
scoped projects, installation, evidence, and security. Four original figures
cover architecture, observed task-list reconciliation, record lifecycles, and
illustrative input accounting.

`1.11.0-alpha.2`**. It connects ROOT rules/planning and observed task deltas with
Agent 0/X/Y/Z, Agent Alpha, ten AUTOBOT references, DATA, tools, and named
`.SYSTEMXP` scopes. Current command manuals remain authoritative for executable
