the beta.3 visual edition: four system maps, seven detailed agent guides, and
one combined atlas. The
[reading-order text alternative](Reference/visual-guide.md) provides every
folder location, example prompt, CLI route, process, and boundary without
requiring the images. The [asset record](Reference/ASSETS.json) lists exact
current file hashes and generated-art provenance.

## Combined atlas

[Open the full-size atlas](Infographics/systemx-atlas.svg) ·
[Read the complete atlas description](Reference/visual-guide.md#combined-atlas).
The atlas is assembled only after the eleven individual guides are finalized.
It is an overview; use each linked full-size panel for dense commands and text.

The [beta.3 8K PNG export pack](https://github.com/WayneTechLab/dotSYSTEMX/releases/download/v1.11.0-beta.3/dotsystemx-1.11.0-beta.3-current-graphics-8k.zip) is available as a separate GitHub release asset for offline or print use. The portable template retains only the twelve canonical SVGs.

The SVGs declare a 7680 × 4320 canvas with exact selectable vector labels,
functional icons, `<title>` and `<desc>` metadata, and a separate generated
illustration. The canvas size does not imply native 8K raster-art detail. Color
is supplemental to printed labels and the full text companion. These graphics
explain source behavior; they do not activate providers, install a native IDE
binding, grant access, certify a device, or deploy an application.
