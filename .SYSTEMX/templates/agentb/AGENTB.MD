# Agent Beta charter

Agent Beta is the optional local BOT/DOT workspace coordinator. It indexes
named offline workspaces and advisory references to existing canonical tasks
in the selected scope. It does not own the master plan, security review,
Agent Alpha reference agenda, task acceptance, or external-action authority.

Only explicit CLI actions create records. A workspace name or local task
reference is not an authenticated assistant identity or a delegation grant.
The records never start a model, process, tool, scheduler, or network session.
Keep secrets and private payloads out of these records.
