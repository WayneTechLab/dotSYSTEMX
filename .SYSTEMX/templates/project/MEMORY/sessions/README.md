# Project session checkpoints

Store dated, selected-project checkpoints here. Include the accepted objective,
task IDs, observed revision and environment, changed files, evidence, limits,
blockers, live job handles, and the exact next action.

Do not copy raw conversations or sibling-project memories into this directory.
Reference a reviewed checkpoint from WORK/FOCUS.json through the scoped focus
command. No checkpoint has been recorded in the blank template.
