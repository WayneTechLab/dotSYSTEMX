# Local project status

The scoped refresh-status command previews a derived STATUS.json. --apply
writes only this scope's snapshot, and identical inputs do not rewrite it.
Rebuild the snapshot after task, focus, or role changes; verify its source hashes
before using an older saved snapshot.

The snapshot describes records, not a live process, service, deployment, or
completed application. This folder does not synchronize files, Git, Drive,
messages, or external services. Configure any transport separately and retain
its own logs and evidence.
