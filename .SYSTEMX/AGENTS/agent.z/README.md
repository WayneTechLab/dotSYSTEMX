# Agent Z: evidence review and scorecards

This is a standard role definition, not a running worker. Activate its scoped
records with `roles-init --apply`; the public registry stays blank except Agent 0
for compatibility with existing installation managers. Preview setup first.

Read the [Agent Z guide](../../docs/AGENT-Z.md). Keep this role's records scoped to
the selected root or child project. The host environment supplies any model,
runtime, scheduling service, and external permissions. Agent 0 or the user
retains task acceptance and integration authority.
