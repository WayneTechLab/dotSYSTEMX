# Session archive

Store sanitized checkpoints here when adopting the template. Use a unique name
such as `YYYY-MM-DDTHH-MM-SSZ_TASK-001_agent.1.md` and the
[session template](../../templates/SESSION-CHECKPOINT.md).

Keep only a short current checkpoint in project or agent memory and link the
relevant archive. Do not preload this entire archive into every session. Never
store credentials, full private transcripts, or customer data here.
